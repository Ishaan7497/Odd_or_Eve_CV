# Odd or Eve Computer Vision

A computer vision implementation of the "Odd or Eve" hand game that uses image recognition to detect hand gestures and finger counts.

## About

This project extends the classic "Odd or Eve" (Hand Cricket) game by using computer vision techniques to detect and recognize hand gestures in real-time video input. Players can play the game by showing their hand to the camera.

## Features
- Hand gesture recognition
- Finger counting using CV
- Real-time video processing
- Python implementation
- OpenCV-based

## Installation

Clone the repository:

```bash
git clone https://github.com/Ishaan7497/Odd_or_Eve_CV.git
cd Odd_or_Eve_CV
pip install -r requirements.txt
```

## Usage

Run the game with your webcam:

```bash
python odd_or_eve_cv.py
```

Show your hand to the camera and let the system detect your finger count!

## Requirements
- OpenCV
- NumPy
- Python 3.6+
